# Changelog

This file records notable changes to NihongoHub Server.

NihongoHub Server is currently in the Demo development stage

## [0.0.1-beta] - 2026-11-29

Initial Demo release.

### Added

- Basic user authentication.
- User password management.
- Vocabulary creation, editing, deletion, and search.
- Vocabulary notebook creation, editing, deletion, and listing.
- Notebook search by tag.
- Adding and removing vocabulary entries in notebooks.
- Server status checking.

---

## Change Categories

- **Added**: New features, APIs, or configuration options.
- **Changed**: Changes to existing features, API behavior, data structures, or configuration options.
- **Fixed**: Bug fixes and corrections to unexpected behavior.
- **Security**: Security fixes and improvements.
- **Removed**: Removed features, APIs, or configuration options.

When preparing a release, organize the completed changes under the corresponding version and add the release date.

For changes that may affect client compatibility, clearly describe the impact on APIs, data structures, and configuration.
