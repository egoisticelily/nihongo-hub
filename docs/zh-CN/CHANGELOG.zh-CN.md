# 变更日志

本文件用于记录 NihongoHub Server 的重要变更。

NihongoHub Server 目前处于 Demo 开发阶段

## [0.0.1-beta] - 2026-11-29

首个 Demo 版本。

### 新增

- 基础用户身份验证功能。
- 用户密码管理功能。
- 单词的创建、修改、删除和搜索。
- 单词本的创建、修改、删除和列表查询。
- 根据标签搜索单词本。
- 向单词本添加和移除单词。
- 服务器状态检查。

---

## 变更分类

- **新增（Added）**：新增功能、API 或配置项。
- **变更（Changed）**：修改现有功能、API 行为、数据结构或配置项。
- **修复（Fixed）**：修复已知问题或异常行为。
- **安全（Security）**：安全相关的修复或改进。
- **移除（Removed）**：移除已有功能、API 或配置项。
