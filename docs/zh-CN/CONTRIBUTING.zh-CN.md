# Contributing

感谢你关注 NihongoHub Server。

本项目目前处于 Demo 开发阶段，由单一维护者负责主要开发和维护。欢迎通过 Issue 提出问题或建议，也欢迎提交 Pull Request，但所有外部贡献均需要经过维护者评估，不保证一定合并。

## 提交问题

提交 Issue 时，请尽量说明：

- 问题涉及的功能或 API。
- 使用的版本、分支或 Git Commit。
- 运行环境。
- 复现步骤。
- 实际结果与预期结果。

请勿在公开 Issue 中提交密码、JWT、密钥、证书、用户数据或其他敏感信息。

安全漏洞请按照 [SECURITY.md](SECURITY.md) 中的说明，通过私密渠道报告。

## 提交 Pull Request

在开始较大规模的修改前，建议先创建 Issue 讨论修改目的和实现方向，避免重复工作或与项目设计方向冲突。

提交 Pull Request 时，请：

- 说明修改的目的和具体内容。
- 尽量保持修改范围集中，避免夹带无关重构。
- 保持现有项目的代码风格和命名习惯。
- 对 API、数据结构和配置项的变化进行明确说明。
- 提供适当的验证步骤，并说明实际验证结果。

维护者可能要求调整实现方式，也可能因项目规划或设计方向而拒绝合并。

## 代码与安全要求

请勿提交以下内容：

- 真实的用户密码或账号凭据。
- JWT 密钥及其他访问密钥。
- 私钥、证书和证书密码。
- 个人数据或真实用户数据库。
- 与本次修改无关的构建产物或运行时文件。

请使用虚构数据进行开发和验证。

## 兼容性

项目目前仍处于 Demo 阶段，API、数据结构和配置格式可能发生变化。

涉及 API、数据结构或配置格式的修改，应在 Pull Request 中说明可能受到影响的客户端或已有部署。

## 许可

提交贡献即表示你同意，该贡献按照本项目的 MIT License 许可条款进行分发。
