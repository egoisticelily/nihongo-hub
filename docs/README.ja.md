NihongoHub は、日本語の単語を管理したり、練習したりするための学習プラットフォームです。

このプロジェクトは、日本語を勉強している人が、単語をもっと覚えやすくすることを目指しています。

スマートフォンなどで単語を練習するとき、いくつかの問題があります。例えば、スマートフォンの日本語入力は、入力した文字から言葉を予想したり、変換候補を出したりします。また、アプリによっては、自分が実際に勉強した単語を使って練習することが難しい場合もあります。

このプロジェクトは、これらの問題を解決し、ユーザーが自分で管理できる日本語学習システムを作ることを目指しています。

ユーザーは好きな単語を追加し、自分の目的に合わせて単語帳に分けて整理できます。また、選んだ単語帳を使って、単語の練習やテストをすることもできます。

入力機能では、独自の日本語入力機能を提供する予定です。スマートフォンなどに入っている日本語入力を使わずに、ひらがな・カタカナ・漢字を入力できるようにします。これにより、日本語入力の予測や変換候補に答えを邪魔されることを防ぎます。

単語のテストでは、選択肢から答えを選ぶのではなく、正しい漢字やかなを実際に入力して答えます。

まずは、上記の機能を開発する予定です。今後、必要に応じて新しい機能を追加することもあります。

現在はブラウザで使う形を中心に開発しています。将来はスマートフォン向けのアプリも開発する予定です。

## 主な機能

- **日本語入力機能：** スマートフォンなどの日本語入力を使わずに、漢字やかなを入力できます。
- **単語の練習とテスト：** 答えを実際に入力して、単語を覚えたかどうかを確認できます。（成績を記録する機能はまだありません）
- **単語の管理：** 漢字、かな、アクセント、意味、メモなどを管理できます。
- **単語帳の管理：** 単語帳を作成し、自分でタグを追加できます。
- **ユーザーの管理**

上記は、このプロジェクトで開発を予定している機能です。すべての機能が実装されているわけではありません。

## 技術スタック

- **バックエンド：** C# / ASP.NET Core Minimal API (.NET 10)
- **データベース：** LiteDB
- **認証：** JWT
- **ログ：** Serilog
- **フロントエンド（予定）：** HTML、CSS、JavaScript

## リポジトリ構成

- `web/` — フロントエンドのソースコード（予定。現在のリポジトリにはありません）
