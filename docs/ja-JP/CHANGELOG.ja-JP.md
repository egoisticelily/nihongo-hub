# 変更履歴

このファイルでは、NihongoHub Server の主な変更内容を記録します。

NihongoHub Server は現在 Demo 開発段階です

## [0.0.1-beta] - 2026-11-29

最初の Demo リリース。

### Added

- 基本的なユーザー認証機能
- ユーザーパスワードの管理機能
- 単語の作成、編集、削除、検索
- 単語帳の作成、編集、削除、一覧取得
- タグによる単語帳の検索
- 単語帳への単語の追加と削除
- サーバーステータスの確認

---

## 変更カテゴリ

- **Added**：新しい機能、API、設定項目の追加
- **Changed**：既存機能、API の動作、データ構造、設定項目の変更
- **Fixed**：不具合や予期しない動作の修正
- **Security**：セキュリティに関する修正や改善
- **Removed**：機能、API、設定項目の削除
