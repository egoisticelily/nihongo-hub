NihongoHub Server は、NihongoHub プロジェクトのサーバー側のプログラムです。ユーザー認証、データの保存、クライアント向けの HTTP API を提供します。

このプロジェクトは、ユーザーが自分でサーバーを動かし、管理できる日本語の単語管理サービスを目指しています。ユーザーは自分のサーバーを動かし、対応するクライアントを使って、日本語の単語や単語帳などを管理できます。

NihongoHub は、クライアントとサーバーを分けた設計です。サーバーはデータや処理を担当し、クライアントは画面や機能を提供します。ユーザーは自分のサーバーを用意し、NihongoHub API に対応したクライアントから接続できます。

## プロジェクトの構成

NihongoHub は現在、サーバーと別のクライアントで構成されています。

- **NihongoHub Server：** このリポジトリです。サーバー機能、データの保存、ユーザー認証、HTTP API を提供します。
- **NihongoHub App：** Flutter で開発した Android / iOS アプリです。スマートフォンでの操作や、日本語の単語練習などの機能を提供します。

クライアントのリポジトリ：[egoisticelily/nihongohub-app](https://github.com/egoisticelily/nihongohub-app)

NihongoHub Server は、誰でも使える共通のサーバーを提供していません。ユーザー自身でサーバーを用意し、クライアントにサーバーのアドレスとアカウント情報を設定する必要があります。

## 現在の機能

現在の Demo では、次の基本機能を実装しています。

- **ユーザー認証**
- **ユーザー情報の確認**
- **パスワード管理**
- **日本語の単語管理**
- **単語の検索**
- **単語帳の管理**
- **単語と単語帳の関連付け**
- **サーバーの状態確認**

## まだ実装していない機能

- **一般ユーザーのアカウント作成**
- **管理者による他のユーザーの管理**
- **単語練習に関するサーバー機能**

## 使用技術

- **言語：** C#
- **フレームワーク：** ASP.NET Core Minimal API (.NET 10)
- **データベース：** LiteDB
- **認証：** JWT
- **パスワードのハッシュ化：** BCrypt
- **ログ：** Serilog

## 使い方

### 必要な環境

- .NET 10 SDK

### ソースコードの取得

```bash
git clone https://github.com/egoisticelily/nihongo-hub.git
cd nihongo-hub
```

### ビルド

`src/` ディレクトリに移動し、.NET CLI を使って通常の方法でビルドまたは発行してください。

### サーバーの起動

Release パッケージを使う場合は、実行ファイルをそのまま起動できます。

自分でビルドする場合は、実行ファイルとして発行してから起動することをおすすめします。

初めて起動するとき、プログラムのあるディレクトリに `Config` ディレクトリを作成します。また、必要に応じて設定ファイルとデータベースを自動で作成します。

データベースにユーザーがいない場合、初期管理者アカウントを作成します。最初のログインに必要な情報は、次のファイルに保存されます。

```text
Config/initial-admin-credentials.txt
```

この情報を安全に保管してください。最初のログイン後、初期パスワードを変更してください。このファイルやパスワードを他の人に共有しないでください。

## サーバーの設定

初めて起動するとき、次のファイルとディレクトリを作成します。

```text
Config/
├── config.json
├── nihongo.db
└── initial-admin-credentials.txt
```

- `config.json`：サーバーの設定ファイルです。
- `nihongo.db`：デフォルトの LiteDB データベースファイルです。
- `initial-admin-credentials.txt`：初期管理者のログイン情報です。このファイルは、初期管理者アカウントを作成するときだけ作られます。

サーバーのアドレス、ポート、HTTPS、データベースのファイルパス、JWT などの設定は、`config.json` で管理します。

デフォルト設定では HTTP を使い、`0.0.0.0:5000` で接続を待ちます。この設定は、ローカルネットワークや安全なネットワークでのテスト用です。そのままインターネットに公開しないでください。

インターネットや安全ではないネットワークから接続する場合は、HTTPS を設定し、サーバーへのアクセスを制限してください。

設定ファイル、特に JWT キー、HTTPS 証明書、証明書のパスワードを安全に保管してください。設定ファイルやデータベースファイルを公開しないでください。

## API

サーバーは HTTP API を使って、クライアントに機能を提供します。

主な API は次のとおりです。

- 認証（Auth）
- ユーザー関連（User）
- 日本語の単語管理（Words）
- 単語帳管理（Vocabulary Notebooks）
- サーバー状態の確認（Status）

API の詳しい説明は、別のドキュメントで案内する予定です。
