NihongoHub 是一个用于日语词汇管理与练习的日语学习平台。

本项目旨在帮助日语学习者更好地记忆日语单词。在日语学习过程中，如果希望使用手机等设备进行单词练习，往往会遇到一些问题。例如，系统日语输入法可能会通过自动联想、候选词和预测功能影响用户的实际输入过程；部分应用也无法完全根据用户自己学习和整理的词汇进行练习。

本项目旨在解决上述问题，同时构建一个由用户自主管理的日语学习系统。用户可以自由地向系统添加日语单词，并根据自己的需求将单词整理到不同的单词本中。用户也可以根据所选的单词本进行练习和测试。

在输入方面，前端将提供自定义日语输入功能，使用户无需依赖系统日语输入法即可输入假名和汉字，避免受到系统输入法预测功能的干扰。

在单词测试中，用户需要实际输入对应的汉字或假名作为答案，而不是通过选择题完成测试。

目前计划优先实现以上功能，后续可能根据实际需求增加其他功能。

项目目前以浏览器端为主要开发方向，未来计划开发对应的移动端 APP。

## 核心功能

- 自定义日语输入功能：无需依赖系统日语输入法，即可输入汉字和假名。
- 日语单词练习与测试：通过实际输入答案检验单词掌握情况。（成绩记录功能尚未实现）
- 日语词汇管理：支持汉字、假名、音调、释义和备注等信息。
- 单词本管理：支持创建单词本，并添加自定义标签。
- 用户管理功能。

以上内容描述的是项目计划实现的功能，并不代表所有功能均已实现。

## 技术栈

- **后端：** C# / ASP.NET Core Minimal API（.NET 10）
- **数据库：** LiteDB
- **身份认证：** JWT
- **日志：** Serilog
- **前端（计划）：** HTML、CSS 和 JavaScript

## 仓库结构

- `src/` — 后端源代码
- `web/` — 前端源代码（计划目录，当前仓库尚未包含）
